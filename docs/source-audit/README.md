# Source audit (Phase 0)

Generated by `npm run audit:fetch` and `npm run audit:census` from immutable, checksummed snapshots
in `data/raw/` (gitignored; recreate with `npm run audit:fetch`). The JSON files here are what the
documentation's *Source audit* and *Mapping coverage* pages render.

| File | What |
|---|---|
| `sources.json` | every downloaded file: URL, bytes, SHA-256, upstream update time, retrieval time, ETag |
| `scryfall-census.json` / `.md` | field census of **all_cards** (547,953 card objects, all languages): per JSON path presence, nulls, types, top values, per-layout presence; identity placement; drift vs. documented fields |
| `scryfall-oracle-census.json` / `.md` | the same for **oracle_cards** (one object per Oracle ID) |
| `tagger-profile.json` / `.md` | Tagger Oracle and art tags: counts, weights, parents, depth, DAG check, child/parent consistency, cross-check with Scryfall IDs |
| `spellbook-profile.json` / `.md` | Commander Spellbook variants: field census, statuses, templates, features, identities, Scryfall cross-check |
| `type-line-residue.json` | type-line words that are not in Scryfall's catalogs (input to RQ-TY-2) |

## Headline findings that shaped the draft

- **Format change:** bulk files are JSONL.gz now; the fetcher reads the manifest dynamically.
- **Reversible cards:** `oracle_id` sits on the faces, never at the root, only for `reversible_card`
  (see `oracleIdPlacement`). Every other layout has a root `oracle_id`.
- **New layouts** since the plan was written: `prepare` and `front_card` (ADR-0004).
- **Schema drift vs. documented fields:** new image renditions (`art`, `crop`, `display`, `grid`,
  `jpeg`, `thumb`), `resource_id`, `image_updated_at`, face-level `flavor_name`; legality formats
  `competitivebrawl` and `tlr` are new, `explorer` and `historicbrawl` are gone. All are kept
  (vocabulary concepts, or deferred with a note in `mappings/`).
- **Tagger:** weights are almost always `median`. Multiple parents are common, especially for art
  tags. Both hierarchies are DAGs in this snapshot.
- **Spellbook:** recipes appear only as IDs. Extra fields (`salt`, `bracketTag`, `popularity`,
  per-vendor prices, variant legalities) are deferred with notes.
